# Encantada Personalizados
Tienda estática en español. Catálogo, personalización, carrito local y solicitud por WhatsApp.

## Cloudflare Pages
Conectar el repositorio, elegir rama main, Framework None, comando de compilación vacío y directorio de salida `dist`.

## Datos comerciales pendientes
Confirmar WhatsApp principal, titular/número/QR de Yape, presentación de canilleras (unidad o par), precio de cuadros para papá, plazo de fabricación, zonas/costo de entrega y política de cambios.
No hay pasarela de pago ni verificación automática de Yape. La coordinación y comprobación son manuales por WhatsApp. No hay servidor ni panel de administración.

## Editar
Productos y variantes: `dist/app.js`. Textos y contactos: `dist/index.html`. Apariencia: `dist/style.css`. Fotos: `dist/assets/`.
No subir capturas privadas de conversación, credenciales ni comprobantes de clientes al repositorio.

Cuadros arte: 20x40 S/45; 40x60 S/55; 60x80 S/75. Capturas de conversaciones excluidas del sitio y del repositorio. Logo original integrado en carga, cabecera, portada, fichas, carrito y pie.
